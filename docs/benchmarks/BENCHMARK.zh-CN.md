[English](BENCHMARK.md) · [项目首页](../../README.zh-CN.md)

每段视频各进行一次双轮对比。对这三段视频，DeepSeek Harness 启用 Watch Video 后，**未缓存输入 token 减少 66.8–69.5%**，**耗时缩短 57.3–88.9%**。Codex 的三组测试总 token 均有下降，Dailymotion 的未缓存输入有所增加。结果反映的是 Agent 在这些样本中的工作流程。

## 测试设置

- 每组 A/B 使用相同的本地视频和两条提示词，各自从新会话开始，追问留在同一会话。各组的输入通过 SHA-256 校验一致。YouTube 两侧还获得了同目录下相同的英文 SRT 字幕文件。其余两个样本未提供字幕。
- **A** 启用了 Watch Video Skill 和 stdio MCP 服务器，版本为 [`739a874`](https://github.com/secretpot/watch-video/commit/739a8748e471db8b40fb6af0ad39dd07ec56f818)。**B** 未启用这两项功能。两侧都可使用能写入工作区的 shell 和普通图像工具。B 自行决定如何用 FFmpeg 和 Whisper 提取画面、读取字幕或转写语音，帧数和处理策略均由 B 决定。该对照反映 Agent 自行收集视频证据时的表现。
- Harness 的六个会话都在同一台 Apple Silicon Mac 上串行运行，使用 Qwen3.8‑Flash high（`Qwen3.8-Flash-Next-oQ6e-mtp`）。网页工具已禁用。Bilibili 对照组在运行期间通过 shell 联网下载了 Whisper 权重。独立的 Codex 会话使用 GPT‑6 Luna high，工具联网已禁用。Codex 的 YouTube 和 Dailymotion 测试短暂重叠。一次 Codex Bilibili 对照运行打开了较早运行留下的图片，因此被排除。报告中的该组结果来自串行运行。
- **总 token** 包含模型的缓存输入、未缓存输入和输出。**未缓存输入**不计缓存读取。Harness 的请求数按原生会话日志中纳入计量的助手生成事件统计。Codex 的请求数按不同的 token 用量更新统计。总量按 token 数表示，无需假设价格。耗时为两个活跃轮次之和，计入工具运行，排除提前准备本地视频及两次提问之间的间隔。

视频从公开链接获取，在计时前准备为本地文件。另用测试构建检查了三个站点的链接，均生成了分镜图。YouTube 提供了人工制作的英语字幕轨，Dailymotion 使用了本地 Whisper，Bilibili 在该链接检查中关闭语音识别后返回了九个章节区间。公开视频提取取决于上游站点和提取器。

## 回答核查与限制

- **YouTube。** Harness 两侧均引用了机械手的台词，起止时间与原字幕一致，为 00:30.800–00:34.000。A 的概览将人工制作的 SRT 误标为语音识别结果。B 又运行了一次多余的语音识别并等待其完成，这加大了耗时差距。在 Codex 中，两侧均给出了正确台词。A 的时间与原字幕一致，B 给出的区间更宽。
- **Dailymotion。** 两个宿主的 A/B 都识别出在 03:19.463 从昏暗撞击坑升起的蓝色扇形颗粒，并将其与 2009 年 LCROSS 任务联系起来。该任务在月球南极附近一处永久阴影撞击坑中探测到了水和其他化学物质。旁白的时间区间随 Whisper 字幕分段而变化。
- **Bilibili。** Harness 两侧都解释了作者为什么认为严重的恶行依赖有组织的链条。A 提交的措辞与字幕不完全一致，精确引文查找失败。它改用缓存的备用字幕片段作答，给出的引文区间较宽，为 00:14:30.320–00:14:49.920。B 下载了更大的 Whisper 模型，重新转写本地音频，并用画面上的文字校正识别错误，给出的区间更窄，约为 00:14:30.2–00:14:38.3。在 Codex 中，A 引用了所问的开头一句，区间为 00:14:30.320–00:14:33.480。B 引用了大约 00:16:32 的后续例子。
- 三段视频各侧均仅测一次，对概览和追问做了抽查。Shell 操作策略、缓存复用、模型输出长度及语音识别结果都可能变化。Harness 的 Bilibili A/B 尤其涉及不同的语音识别流程，耗时比计入了模型自行选择的额外工作。
